# Automatically email campaign PDF attachments

Status: won't do

## Description
Request to attach aggregate campaign reports to scheduled outbound review emails. This is not subscriber CSV export, but DOC-012 excludes automatic distribution under D-27.

## Comments
- Fenna Orr (2026-07-07): The in-app review reminder can link to an access-checked report view; it need not send an attachment.
- Sora Pell (2026-07-09): Won't do because the scheduler cannot revalidate report permissions at attachment-send time. D-27 explicitly postpones that capability.
- Mira Venn (2026-07-10): Closing the shortcut. TCK-004 still has no release evidence beyond ready for QA; this ticket does not imply PDF availability.
