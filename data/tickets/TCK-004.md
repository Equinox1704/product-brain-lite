# Add aggregate campaign report PDF attachment

Status: Ready for QA
Owner: Fenna Orr
Related: DOC-003; CHAT-002; CHAT-005

## Description
Generate a PDF containing campaign name, send date, delivered count, opens, clicks, and metric definitions. Exclude recipient-level rows, subscriber addresses, and custom subscriber fields. This feature is a campaign analytics report, not subscriber CSV export.

## Acceptance criteria
- The PDF identifies the campaign and reporting timestamp.
- The attachment contains aggregate counts only.
- The report labels opens as an estimate rather than verified readership.
