# Preference copy update after publication policy approval

Owner: Elian Marr. This record updates the copy restriction in DOC-009 after DOC-005 approved publication-scoped unsubscribe handling for new events. TCK-005 still requires rollout evidence; the copy must not get ahead of enabled behavior.

## Decisions
D-30: We replaced D-21's blanket postponement of publication-specific confirmation copy with a rollout-gated copy package because D-12 now defines publication scope for new unsubscribe events. The package may name a publication only when the new policy is enabled for that workspace and event.

## State-aware language
A new publication opt-out should explain which named sending stream stops. A workspace-wide opt-out must still say that all publications stop. Existing workspace-wide records remain effective under D-13 and must never be displayed as though only one publication were suppressed.

Hard bounces remain a separate workspace-wide delivery restriction under D-19. The preference page must not offer a subscription change that claims to make a permanently unreachable address deliverable. D-22's exclusion of promotional content remains unchanged.

## Acceptance and coordination
TCK-009 now includes both pre-rollout and post-rollout wording tests. The enablement flag and suppression state jointly select the copy; audience membership is not a substitute for publication identity. Regression coverage must include a historical workspace-wide unsubscribe followed by a visit through a newly named publication.

This decision approves content and gating rules only. It does not declare the publication migration deployed, reopen subscriber CSV export, or authorize campaign report attachments. Release notes must separate these unrelated workstreams.
