# Audience import preview and recoverable validation

Owner: Tavin Reed. Scope: a one-time CSV upload into a selected Pulse audience. This workflow does not maintain an ongoing connection to another system and does not download existing subscribers.

## Product contract
The administrator maps columns, previews validation results, and confirms accepted rows before any audience membership changes. A preview reports invalid addresses and missing required values without displaying unrelated workspace records. Uploading a file alone does not complete the import task in DOC-002; a successfully committed import does.

## Decisions
D-15: We chose partial acceptance with an explicit preview because one malformed row should not force administrators to repair an otherwise usable file before understanding the problem. Confirmation shows accepted and rejected counts separately.

D-16: We postponed downloadable rejected-row files because the existing field-authorization gap could expose submitted custom attributes through a second download path. The first version provides an authenticated on-screen error summary instead. This does not change D-05, which postpones subscriber CSV export.

## Acceptance and boundaries
A confirmed import must not revive any suppressed address. Duplicate normalized addresses update permitted fields under a documented merge rule and count separately from newly created subscribers. Retrying the same confirmation must not create duplicate memberships.

TCK-006 owns the preview implementation. Ongoing subscriber synchronization belongs to DOC-007 and must not be described as an automated version of this upload without specifying conflict behavior. A later decision is required before downloadable rejection artifacts can enter scope.
