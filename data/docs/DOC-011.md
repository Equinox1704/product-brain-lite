# Subscriber portability roadmap remains authorization-blocked

Owner: Sora Pell. Scope: the roadmap state of subscriber CSV export after requests for migration support. This is distinct from aggregate campaign PDF reports and from inbound CSV imports.

## Current assessment
DOC-003 and D-05 postponed subscriber CSV export because field-level access restrictions are not enforced reliably by the proposed read path. A later customer request does not remove that dependency. TCK-003 remains blocked, and TCK-004's aggregate PDF reporting work is not an alternative source of subscriber records.

## Decisions
D-25: We continued postponing subscriber CSV export because the authorization prototype still lacks passing negative-permission tests for restricted custom attributes. No delivery date is approved, and no support-operated subscriber download is introduced by this record.

D-26: We prioritized a permission-test harness before download formatting because a correctly formatted file is still unsafe if it contains unauthorized fields. The harness must exercise cross-workspace isolation and field omission, not only successful administrator reads.

## Review gate
A future release proposal must include the authorized field contract, expiration behavior for download links, audit-event handling, and test results. Completion of the harness alone is insufficient to schedule a release.

TCK-012 tracks this prerequisite separately from the blocked feature ticket. CHAT-010 captures a fictional migration request without promising a workaround. Later roadmap summaries must preserve the distinction between an approved prerequisite, an implemented prerequisite, and a released export capability. D-16's separate rejection-file postponement also remains unchanged.
